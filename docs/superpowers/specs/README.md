# Superpowers Specs

Normative specs live here after behavior has been reviewed or explicitly proposed as a versioned contract.

## Topic Areas

- `runtime/`: runtime contracts, phased boundary work, routing, driver boundaries, and related proof documents
- `workflow/`: Workflow contracts separated into `foundation/`, `evolution/`, and `history/`

Choose the narrowest topic folder that matches the change. Avoid adding flat files directly under `specs/`.

Implementation steps belong under `../plans/`; explanatory design and research do not belong in this directory.
